# Учебное портфолио — CI/CD

Многостраничный статический сайт на HTML и CSS.

- `index.html` — главная страница.
- `about.html` — информация об авторе.
- `projects.html` — учебные проекты.
- `style.css` — оформление сайта.
- `scripts/check_site.py` — проверка файлов перед публикацией.

## Индивидуальная часть

В workflow GitHub Actions добавлен шаг `Check project files`. Перед публикацией скрипт проверяет наличие всех трёх HTML-страниц, файла CSS, а также тегов `<title>`, `<body>` и подключения таблицы стилей.

При каждом push в ветку `main` сначала выполняется проверка. Если она проходит успешно, сайт автоматически публикуется на GitHub Pages.

Локальная проверка: `python scripts/check_site.py`.

Перед сдачей замените текст на страницах на собственную информацию.
